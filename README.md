
# Personal Portfolio Website

A simple personal portfolio website built using **HTML5** and **CSS3**. The website consists of two pages: a **Home** page that introduces my profile and a **Contact** page where visitors can find my contact information.

## Features

* Clean and simple user interface
* Responsive design
* Home page with personal introduction
* Contact page with contact details
* Built using only HTML and CSS

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was created to practice the fundamentals of front-end web development and to showcase my basic web design skills using HTML and CSS.

* Add more portfolio sections (Projects, Skills, About Me)
* Include JavaScript for interactive features
* Improve responsiveness and styling
* Add a contact form
